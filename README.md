# Guess the Sport — Heinz

An interactive opener for an IMC group presentation on the Heinz
*“The tomatoes that want to win are all in Heinz”* campaign
(15th National Games of China, Guangzhou, November 2025).

Six tomato calyxes, six sports. The audience guesses; we reveal.

**Play:** https://miabeacurator.github.io/heinz-guess-the-sport/

## Controls

| Key | Action |
|---|---|
| `Space` / click | reveal, then advance |
| `→` / `←` | next / previous |
| `F` | fullscreen |
| `R` | back to start screen |
